# Paket SK untuk Akreditasi Perguruan Tinggi BAN-PT 2027

Folder ini berisi draf 32 Surat Keputusan (SK) sebagai dokumen bukti akreditasi STEI Fithrah Insani, dibagi menjadi dua paket:

- **Paket I (F-SK-AKR-01 s.d. 16):** fokus bidang Wakil Ketua II (Standar 2, 3, dan 6), ditambah SK Tim Akreditasi.
- **Paket II (F-SK-AKR-17 s.d. 32):** mencakup Standar 1, 2, 4, 5, dan 7 untuk Ketua, LPM, WK I, WK III, dan LPPM.

Setiap berkas sudah memuat struktur lengkap: kop, nomor, konsiderans (Menimbang, Mengingat, Memperhatikan), diktum, blok tanda tangan, tembusan, dan lampiran. Format: A4, Times New Roman 12, margin 2,5 cm.

## Sumber data asli yang dipakai

- **Izin institusi:** Keputusan Dirjen Pendidikan Islam Kemenag Nomor 1137 Tahun 2023 tentang izin perubahan nama STEI Ar-Risalah menjadi STEI Fithrah Insani. Data ini dikutip dari SK Renstra Nomor 421.4/001/STEI.FI/II/2024 (`1. AKREDITASI & REGULASI/Dokumen Strategis/RENSTRA STEI FI.docx`).
- **Visi, misi, tujuan, sasaran, strategi (SK 17):** RENOP STEI FI Bab 2. Ejaannya dirapikan tanpa mengubah isi.
- **Aspek Renstra (SK 18):** RENSTRA STEI FI Bab I huruf C.
- **Kalender akademik (SK 27):** `KALENDER_AKADEMIK_TA_2026_2027.xlsx`.
- **Visi penelitian dan tema riset unggulan (SK 30):** `lppm/.../F-LPPM-01-01_RIP-STEI-FI.docx`.
- **Nilai dan jenis pelanggaran etika (SK 21):** `lppm/.../F-LPPM-08-01_Pedoman-Etika-Penelitian.docx`.

SK yang sudah punya templat di folder unit masing-masing tidak dibuat ulang. Contohnya: Standar SPMI, Tim Auditor AMI, Sasaran Mutu, SK Mengajar, DPA, Pembimbing dan Penguji Skripsi, Tim Kurikulum, Penerima Beasiswa, Pengurus Ormawa, SK APB, dan SK Izin Studi.

## Yang harus dilengkapi sebelum ditandatangani

1. **Ejaan nama institusi.** Semua SK memakai "Fithrah", sesuai SK Dirjen Pendis 1137/2023. Templat lama di folder `wk2/`, `lpm/`, dan `wk1/` masih memakai "Fitrah". Cocokkan dengan naskah asli SK izin, lalu tetapkan lewat F-SK-AKR-13.
2. **Format nomor SK.** Draf memakai format `___/SK/STEI-FI/bulan/tahun` (format templat repo). SK Renstra 2024 memakai format `421.4/001/STEI.FI/II/2024`. Pilih satu format lalu tetapkan lewat F-SK-AKR-03.
3. **Isian kosong (`______`).** Nama pejabat, NIDN, nomor dan tanggal SK, alamat kampus, nomor akta yayasan, dan SK pengangkatan Ketua.
4. **Nominal dan target angka** (biaya, ambang otorisasi, target Renstra/RIP, batas kemiripan naskah, target respons tracer study) dikosongkan.
5. **Usulan yang perlu disepakati rapat pimpinan:** bobot penilaian kinerja (SK 09); kehadiran 75%, konversi nilai, batas cuti, dan predikat kelulusan (SK 28); masa jabatan 2 tahun (SK 02, 20, 21).
6. **Logo** pada lampiran F-SK-AKR-13 masih berupa tempat kosong.

## Membuat ulang berkas

Isi SK tersimpan sebagai data di `_generator/content.js` (Paket I) dan `_generator/content2.js` (Paket II). Setelah mengubah isinya, jalankan:

```bash
cd _generator
npm install docx   # sekali saja
node gen.js ..
```
